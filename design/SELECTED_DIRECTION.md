# Selected direction contract: macOS Air

THESIS: A quiet, legible macOS camera utility. Protection can be understood and controlled at a glance.
OWN-WORLD: Pale gray navigation rail, white content, blue selection/action, rounded hairline panels, precise compact typography, authentic application icons. The user explicitly delegated selection after five Imagegen concepts; 01-macos-air.png was selected. Its preview, inspector and shortcuts composition is the visual authority.
STORY: Identify whether protection has started, start/stop it, inspect the configured model and saved rules, and manage the protected applications. Camera preview is optional; hidden preview continues detection. Detection and shortcut forms share the same system.
FIRST VIEWPORT: Sidebar about 18% of the default window; main title/subtitle above a dominant camera area on the left and compact model/rules plus six app rows on the right; a short shortcut bar below. Chinese/EN control remains visible at top right. Status is textual as well as colored.
FORM: A working native macOS desktop app, with CustomTkinter controls, AppKit OS integration and keyboard navigation. Default content size 1120×760 points, minimum 1000×690 points, DPR 2 on the inspected screen. Keep native title bar; no web dashboard substitution.

Factual adaptations required by product truth: actual eligible-person trigger instead of generated absent-person claim; Cmd+Ctrl+Option+minus instead of generated Shift; real saved rule values instead of invented sensitivity preset; actual installed icons and native window chrome. The SF camera symbol is a platform asset; the selected comp's drawn camera-slash mark is not treated as a logo. Scrollable forms are an adaptation for all fields to remain reachable.

Chinese/English switching must preserve pending form edits and actual stored keycodes; save is explicit for detection/apps/shortcuts. Language, preview and login preferences save immediately. Monitoring is not activated by the upgrade. No camera or app-hiding claim can be inferred from a static preview.
