# Chill Guard Apple 推理验证记录

本地候选分支：`feat/apple-local-inference`。基于 GitHub main `7ead35dc55efb94a49a8c24592dcb9e5778fa2c1`，未推送或发布。

## 已实现

- 可选 Core ML 推理，保留 PyTorch 默认值与失败回退；模型权重和检测尺寸通过导出清单核对。
- YOLO11 COCO 模型的 FP16 导出、RGB 方形预处理、原始框解码、坐标还原与 NMS。
- 监测中切换模型、后端或检测尺寸会重新加载；原生推理失败重试同一帧并显示实际后端。
- 修复重启时设置被反复迁移改写的问题；写入带版本的设置并以临时文件替换，保留旧文件中的有效选择。
- 界面人数与隐藏触发使用同一组筛选后的目标；重复框在主用户选择前去重，避免低置信度的合并框接管主用户。
- 预览留边显示完整画面；状态指示保留运行状态，并优先显示真实失败。
- 生成并验证本地 `.app` / DMG；原生模型和运行库包含在候选包中。

## 本机与依赖

2026-10-08：Apple M4 Pro，48 GB 内存，macOS 27.0.1，arm64，Python 3.12.13。项目依赖保持 Ultralytics 8.4.26、Torch 2.11.0、Torchvision 0.26.0。可选 Core ML 环境增加 coremltools 9.0 和 NumPy 2.3.5。初次使用 NumPy 2.5.3 时转换失败；固定转换器支持的版本后成功。

coremltools 会提示 Torch 2.11.0 超出其最后测试版本。本次实际导出、源代码推理和打包后推理均成功，不能据此扩展为所有模型或设备的兼容保证。

## 速度

同一份 `yolo11s.pt`，检测尺寸 1280，置信度 0.30；使用已安装 Ultralytics 包自带的 `bus.jpg` 和 `zidane.jpg`。每张图先预热 3 次，再连续测试 30 次。表中为预处理、模型执行、坐标还原及 NMS 的总墙钟时间；不含摄像头、规则筛选、UI、声音或隐藏动作。PyTorch 保留原来的矩形填充，Core ML 使用固定方形填充。

| 图片 | PyTorch/MPS p50 / p95 | Core ML p50 / p95 | p50 比值 |
| --- | --- | --- | --- |
| bus.jpg | 59.27 / 68.58 ms | 20.17 / 20.91 ms | 2.94× |
| zidane.jpg | 51.78 / 58.20 ms | 18.72 / 19.48 ms | 2.77× |

较早一次 20 次采样的原配置比较得到约 2.2–2.5×；本机背景负载会影响结果。最初采用两个后端均方形填充的对齐试验得到约 4.6–5.7×，这一数值不能作为相对原程序的加速结论。

Core ML `MLComputePlan` 在 CPU + Neural Engine 配置下，给 241 个操作选择 Neural Engine、2 个操作选择 CPU，717 个常量或未指定设备的操作不纳入有设备的成本统计。估算成本权重为 Neural Engine 95.58%、CPU 4.42%。这是计算计划估算，并非运行时功耗测量。

## 检测与规则

方形输入对齐时，两张图的 PyTorch/Core ML 对应框最小 IoU 分别为 0.9955、0.9928；这里只证明这两个样本的转换结果接近，未计算数据集 mAP。

保留原矩形填充后，`zidane.jpg` 的原始框数为 PyTorch 2、Core ML 3；Core ML 多出一个低置信度合并框。复现确认，该框可能在主用户评分中占优，继而排除另一名真实人物。新增回归测试先失败，改为在主用户选择前去重后通过。后端保持可选，默认仍为 PyTorch。

真实检测器接入 `monitor_loop` 的离线回放使用每图 3 帧，摄像头读取替换为图片，隐藏动作替换为记录器，声音关闭。两种后端在每图每帧的有效人数均为 2，并在达到 3 帧后产生一次模拟隐藏请求。这里的“有效人数”是启发式规则筛选结果；`bus.jpg` 原始检测为 4 框，筛选后为 2，不能作为真实人数准确率的证明。自身排除规则仍需要真实场景标注与校准。

## 验证清单

- 18 项 unittest 通过：设置保存/重载、无版本文件、原生后端持久化、错误类型、面积/缓冲区过滤、允许人数、连续帧门槛、静默、合并重复框、状态、后端回退、校验值、解码和坐标还原。
- 原代码中已观察到设置和过滤触发测试失败；修复后通过。新增合并框测试也经过失败到通过的验证。
- Python 语法检查、`git diff --check` 通过。
- Tk 表单创建和设置解析通过；摄像头、全局快捷键和状态栏初始化在此检查中禁用。未声称完整 UI 视觉验收。
- PyInstaller 构建、临时清洁副本的 ad-hoc 签名验证、DMG 生成通过。
- 冻结 `.app` 的 `--check-inference` 在本地图片上返回 Core ML 实际后端、无回退、有效检测框。
- 冻结 `.app` 选择尚无原生导出的 `yolo11n.pt` 时，明确报告缺失原因，并通过 PyTorch/MPS 返回有效检测框；最终 `.app` 签名校验和 DMG 校验通过。

可重跑命令见 [Apple 推理说明](../docs/APPLE_INFERENCE.md)。详细 JSON 和日志位于本地 `validation/local/`，模型位于 `.models/`，构建位于 `dist/`；这些生成文件不提交。
