# Code of Conduct

## Our standard

Participation in this project is expected to stay respectful, technically focused, and free of harassment.

Examples of expected behavior:

- discuss technical disagreements with evidence
- respect different experience levels
- give actionable feedback
- assume good intent until behavior shows otherwise

Examples of unacceptable behavior:

- personal attacks
- harassment, intimidation, or discrimination
- repeated bad-faith argumentation
- publishing private information without consent
- derailing technical discussions with hostility

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributors that violate this code of conduct.

## Reporting

If the repository enables private security or moderation channels, use those first. Otherwise contact the maintainer directly instead of escalating abuse through public issue threads.
