# Security Policy

## Supported versions

This project is currently maintained on a best-effort basis. The latest `main` branch is the only supported source state.

## Reporting a vulnerability

Do not open a public GitHub issue for security-sensitive findings.

Preferred order:

1. Use GitHub private vulnerability reporting if the repository has it enabled.
2. If private reporting is not enabled, contact the maintainer directly before public disclosure.

When reporting, include:

- affected version or commit
- reproduction steps
- expected impact
- whether camera access, accessibility access, or Apple Events automation are involved

## Response expectations

There is no formal SLA. Reports will be handled as capacity allows.
